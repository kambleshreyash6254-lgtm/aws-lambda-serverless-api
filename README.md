# AWS Lambda & Serverless API

Built a simple serverless API using AWS Lambda and Amazon API Gateway.

## What I did
1. Created a Lambda function (Python) that returns JSON
2. Tested it in the Lambda console
3. Created an HTTP API in API Gateway
4. Connected the GET /hello route to Lambda
5. Tested the live endpoint in the browser

## Live API
PASTE-YOUR-API-URL/hello

## Key learnings
- Serverless means no servers to manage
- Lambda runs code only when triggered
- API Gateway exposes Lambda as an HTTP endpoint
